# Честные блоки

Портретная головоломка в духе Block Blast: поле 8×8, три фигуры за ход, заполненные ряды и столбцы исчезают. Партия кончается, когда ни одна из оставшихся фигур не помещается.

Отличие от типичных клонов — **честная раздача**. В каждом новом наборе есть хотя бы одна фигура, которую можно поставить на текущее поле. Игра не усложняет набор из‑за высокого счёта и не подсовывает заведомо безнадёжную тройку. Рекламы нет, партия сохраняется в браузере и продолжается без сети.

Рабочее название: «Честные блоки».

## Запуск локально

Нужен обычный статический сервер (сервис-воркер и модули не работают с `file://`).

```bash
python3 -m http.server 8765
```

Откройте [http://localhost:8765](http://localhost:8765) и сузьте окно до ширины телефона, либо включите мобильный режим в инструментах разработчика. Альтернатива: `npm start` (это та же команда).

Управление: перетащите фигуру с нижней панели на поле. Палец держит фигуру чуть выше себя, мышь — по центру курсора. На поле подсвечивается, куда она встанет, и какие линии закроются.

## Публикация на GitHub Pages

Сайт лежит в корне ветки и не требует сборки.

1. Залейте ветку `main` на GitHub.
2. Settings → Pages → Build and deployment → Deploy from a branch.
3. Branch: `main`, папка: `/ (root)`. Сохраните.
4. Через минуту игра откроется по адресу `https://<user>.github.io/<repo>/`.

Манифест и сервис-воркер используют относительные пути (`./`), поэтому тот же каталог работает и как проектный сайт в подпапке, и как пользовательский сайт в корне домена. Нужен HTTPS — Pages его даёт. Первый запуск должен быть онлайн: тогда оболочка попадёт в кэш, и дальше игра открывается без сети. Её можно добавить на домашний экран (в Chrome: «Установить приложение»).

## Честная генерация

Фигуры заранее повёрнуты: крутить их в руке нельзя, как в оригинале. Каталог — прямоугольники, уголки, T, S/Z, плюс и несколько пентамино. Код: `js/pieces.js`, правила раздачи: `js/generator.js`.

Свежий набор из трёх фигур:

1. Перебираем все ориентированные фигуры и оставляем те, что хотя бы куда-то встают.
2. Если таких нет (поле полностью занято), раздача невозможна. После стирания линий пустые клетки остаются, поэтому фигура 1×1 почти всегда доступна.
3. **Якорь** — фигура, которая точно встаёт на поле. Сначала равномерно выбирается семейство (домино, уголок, квадрат…), затем подходящий поворот этого семейства. Уголок с восемью поворотами не выпадает чаще одиночной клетки только из‑за числа вариантов. Это гарантия хода, а не «всегда самая мелкая фигура».
4. Две другие фигуры выбираются так же, но из всех семейств, без проверки, влезают ли они. Специально «плохие» фигуры не подсовываются. Очки, серия и номер хода в раздачу не входят.
5. Три фигуры перемешиваются, чтобы якорь не стоял всегда в одной ячейке.

Следующий набор показывается переключателем «Показывать следующий набор» (по умолчанию включён). Он честен на момент раздачи. Если к тому времени, как он станет текущим, ни одна из трёх фигур уже не влезает, **одна** случайная фигура меняется на случайную подходящую. Значок «обновится» предупреждает об этом заранее. Текущий набор так не подменяется: нет хода среди оставшихся фигур — партия окончена.

Проверка: `npm test` и `npm run simulate`. Симуляция играет случайные честные партии и завершается с кодом 1, если гарантия нарушена.

## Очки

За каждую поставленную клетку — 1 очко. Если ход закрыл линии:

- комбо: `10 × (число линий)²` — одна линия 10, две 40, три 90;
- серия: подряд идущие ходы с очисткой. Начиная со второй подряд, добавляется `(серия − 1) × 5 × линии`.

Ход без линии обнуляет серию. Рекорд пишется в `localStorage` (`chestnye-bloki-v1`) вместе с полем, фигурами, темой, языком и звуком. Перезагрузка продолжает ту же партию.

## Офлайн, темы, звук

`manifest.webmanifest` и `sw.js` делают игру устанавливаемой. Четыре темы: классика, тёмная, пастель, дерево. Звук — короткие тоны WebAudio, без файлов; кнопка в шапке его выключает. Тексты интерфейса собраны в `js/i18n.js` (русский, қазақша, English).

Рекламы и платежей нет. В `js/main.js` оставлен комментарий, куда когда-нибудь можно поставить разовую поддержку автора — не баннер и не межстраничную рекламу.

## Структура (для переноса на Flutter/Flame или Godot)

Правила не знают про DOM:

| Модуль | Роль |
| --- | --- |
| `js/config.js` | размер поля, константы очков, ключ сохранения |
| `js/pieces.js` | каталог фигур |
| `js/board.js` | постановка и стирание линий |
| `js/generator.js` | честная раздача |
| `js/scoring.js` | очки, комбо, серия |
| `js/game.js` | состояние партии: `createMatch`, `placePiece` |
| `js/i18n.js` | строки интерфейса |

Оболочка браузера: `storage.js`, `audio.js`, `render.js`, `input.js`, `main.js`. В другой движок переносятся таблицы фигур и функции из первой группы; рисование и ввод пишутся заново.
